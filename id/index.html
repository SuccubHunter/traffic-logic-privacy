Kebijakan Privasi Traffic Logic

Tanggal berlaku: 31 Oktober 2026

Ini adalah terjemahan. Jika terdapat perbedaan dengan versi bahasa Inggris, versi bahasa Inggris yang berlaku.

1. Ringkasan

Traffic Logic dapat dimainkan tanpa pendaftaran dan tidak meminta nama, alamat email, kontak, lokasi, atau akses ke file Anda.

Kebijakan ini berlaku untuk game Traffic Logic: Route Puzzle untuk Android, ID aplikasi com.succubhuntersinc.trafficlogic.game. Pengembang game ini adalah succubhuntersinc (“kami”).

2. Data apa yang diproses

Progres dan pengaturan Anda disimpan di perangkat Anda. Hanya data teknis tentang stabilitas game yang keluar dari perangkat.

DataIsinyaLokasi penyimpanan
ProgresLevel yang telah diselesaikanDi perangkat Anda
PengaturanBahasa, volume, bisukan suara, kurangi animasiDi perangkat Anda
Data teknisLog kerusakan dan kesalahan, informasi tentang aplikasi yang macet, performa, dan konfigurasi aplikasiDi server Unity
ID instalasiID unik untuk instalasi game iniDi server Unity

Saat data teknis dikirim, server Unity menerima alamat IP koneksi Anda. Hal ini diperlukan untuk komunikasi jaringan.

Jika pencadangan Android aktif, sistem dapat menyimpan progres dan pengaturan Anda ke Akun Google Anda. Kami tidak memiliki akses ke salinan tersebut.

Game ini tidak mengumpulkan nama, alamat email, nomor telepon, kontak, lokasi, foto, file, atau data pembayaran Anda. Game ini tidak memiliki iklan, pembelian dalam aplikasi, akun, atau obrolan, dan tidak meminta ID iklan.

3. Tujuan dan dasar hukum

Kami menggunakan data teknis hanya untuk menemukan dan memperbaiki kesalahan dalam game. Kami tidak menggunakannya untuk iklan atau pembuatan profil.

TujuanDataDasar
Menyimpan progres dan pengaturan antarsesiProgres, pengaturanPengoperasian game di perangkat Anda; kami tidak menerima data ini
Menemukan dan memperbaiki kerusakan, kesalahan, dan aplikasi yang macetData teknis, ID instalasiKepentingan yang sah untuk menjaga stabilitas game (Pasal 6(1)(f) GDPR dan aturan serupa di negara lain)

4. Siapa yang menerima data

Kami tidak menjual data. Hanya Unity yang menerima data teknis, dan Google Play mendistribusikan game ini.

LayananPeranDetail
Unity TechnologiesMemproses data teknis dan ID instalasi atas nama kamiPrivasi Unity Diagnostics
Google PlayMendistribusikan game dan memproses data instalasi berdasarkan aturannya sendiriKebijakan Privasi Google

Layanan ini dapat memproses data di luar negara Anda. Kami dapat mengungkapkan data jika diwajibkan oleh hukum.

5. Penyimpanan, keamanan, dan penghapusan

Secara default, Unity menyimpan data pribadi dari laporan kerusakan selama 90 hari. Kami tidak memiliki server sendiri yang berisi data pemain.

  • Di perangkat Anda. Progres dan pengaturan tetap ada sampai Anda menghapus instalasi game atau menghapus datanya di setelan Android. Setelah itu, data hanya dapat dipulihkan dari cadangan perangkat Anda.
  • Cadangan. Cadangan dikelola melalui setelan Android dan Akun Google Anda.
  • Pengiriman. Unity mengenkripsi data teknis saat dikirim.
  • Penghapusan atas permintaan. Kirim pesan kepada kami melalui alamat di bagian 8. Kami tidak memiliki nama atau kontak Anda, sehingga kami mungkin meminta informasi yang membantu menemukan instalasi Anda. Jika tidak dapat menemukannya, kami akan memberi tahu Anda.

6. Anak-anak

Game ini tidak ditujukan secara khusus untuk anak-anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data pribadi mereka. Jika Anda yakin kami telah menerima data anak, hubungi kami dan kami akan menghapusnya.

7. Hak Anda

Tergantung negara Anda, Anda dapat meminta akses ke data Anda, perbaikan atau penghapusannya, serta menolak pemrosesannya.

Game ini tidak memiliki tombol terpisah untuk menonaktifkan laporan kerusakan. Untuk menggunakan hak Anda, hubungi kami. Anda juga dapat mengajukan keluhan kepada otoritas perlindungan data di negara Anda.

8. Perubahan dan kontak

Kirim pertanyaan tentang privasi ke succubhuntersinc@gmail.com. Jika kebijakan ini berubah, kami akan menerbitkan versi baru di halaman ini dan memperbarui tanggal di bagian atas.
